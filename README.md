# yadisk-downloader

Скачивание ваших файлов по **публичным ссылкам Яндекс Диска** с локальным веб-интерфейсом.
Рассчитано на ситуации, когда Диск отвечает нестабильно (ошибки 500, зависания): программа
не останавливается на плохом файле, ведёт учёт ошибок и добирает недостающее повторным заходом.

Только стандартная библиотека Python 3.8+, ничего устанавливать не нужно. Работает на macOS, Windows, Linux.

*English summary:* a dependency-free Python tool with a local web UI that downloads your own files from
public Yandex Disk links and keeps going when the service is flaky: fail-fast on bad files, per-folder
counters (done / left / errors), md5 verification, resumable `.part` files, a preview fallback for photos
and a one-click "retry failed" pass. Public links only, no login or token.

## Windows без установки Python

Готовый `yadisk-downloader.exe` собирается автоматически (GitHub Actions) и лежит в разделе **Releases**
репозитория: скачайте, дважды кликните — откроется браузер с интерфейсом. Windows SmartScreen может
предупредить о неизвестном издателе («Подробнее» → «Выполнить в любом случае»): файл не подписан.

## Запуск

```bash
python3 yadisk.py
```

Откройте http://127.0.0.1:8765, вставьте ссылки (`https://disk.yandex.ru/d/...`), выберите папку и нажмите «Скачать».
Можно и из командной строки:

```bash
python3 yadisk.py --dest ~/Downloads/YandexDisk --threads 10 https://disk.yandex.ru/d/XXXX https://disk.yandex.ru/d/YYYY
python3 yadisk.py --no-ui --dest D:\Photos https://disk.yandex.ru/d/XXXX   # без интерфейса, завершится сам
```

Параметры: `--threads` (по умолчанию 10), `--mode parallel|sequential` (все папки сразу или по очереди),
`--port`, `--dest`, `--data` (где хранится `state.db`).

## Что умеет

- **Счётчики по каждой папке:** скачано · осталось · ошибок · «только превью», общий прогресс, скорость и оценка времени.
- **Не застревает на плохих файлах:** быстрый отказ по таймауту (8 с на ответ), ошибка записывается, программа идёт дальше.
- **Повторный заход:** в конце один раз автоматически повторяет неудавшиеся; кнопка «Повторить неудавшиеся» — вручную.
- **Превью вместо пустоты:** если оригинал фото не отдаётся, сохраняется превью до 1280 px как `имя.preview.jpg`
  (это не оригинал; при следующем заходе программа снова пробует скачать оригинал).
- **Проверка целостности:** размер и md5 (если Диск его сообщает); битый файл не принимается.
- **Докачка:** недокачанные файлы лежат как `.part` и продолжаются с места остановки; перезапуск программы продолжает работу.
- **Список ошибок:** `/api/failed.csv` (кнопка «Список ошибок (CSV)»).
- **Не даёт уснуть** компьютеру во время загрузки (macOS и Windows).
- Веб-интерфейс слушает только `127.0.0.1` и проверяет заголовки Host/Origin.

## Ограничения

- Только публичные ссылки. Это инструмент для **ваших собственных данных**; он не обходит ограничения Диска
  и не может скачать то, что сервер Яндекса не отдаёт. Не связан с Яндексом.
- Если Диск массово отдаёт ошибки, скорость будет низкой — программа просто продолжает пробовать.

## Тесты

```bash
python3 -m unittest tests.test_engine
```

Тесты поднимают локальный «поддельный» Диск (ошибка 500, неверный md5, превью) и проверяют весь цикл.
